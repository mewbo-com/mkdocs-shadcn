# Tooltips

Define an abbreviation once and every occurrence of the term carries a
tooltip. The term is marked with a dotted underline so a reader can tell
there is something to hover.

The HTML specification is maintained by the W3C. A CSS rule targets an
element. Mewbo indexes a repository into a wiki.

*[HTML]: HyperText Markup Language
*[W3C]: World Wide Web Consortium
*[CSS]: Cascading Style Sheets

This uses the `abbr` extension, which ships with Python-Markdown and needs no
theme JavaScript — the browser renders the tooltip itself, so it works with a
keyboard and with a screen reader.
